One page of the world's news for Wednesday, 25 November 2026: the war in Ukraine, Huawei's US verdict, AI-market nerves, Pakistan's first astronaut, the end of the Ábrego García deportation battle, Gaza, and the Gambia's election — drawn as a single broadsheet front page that names its day.

The program writes the day's image to `/output/entry.png`: a 1024×1024 PNG (about 131 KiB) held in this repository, copied unchanged so both runs write the same bytes.

## Run it

```sh
python3 main.py
```

Outside the grader's container, `MAKEFUN_OUTPUT_DIR` stands in for `/output`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
